# Pricing

## Tawi: free

Everything one person does on their own computer is free and open source (Apache-2.0):
- building agents from your documents, with no code
- fine-tuning 15 open models on your own GPU or Apple Silicon Mac, and evaluation
- the 50-prompt safety check
- answering behind an API key, in OpenAI's format too
- deploying with Docker to this machine, or downloading the bundle for any server
- Tawi Drive (5 GB, with version history) and Python notebooks
- as many agents as you like

## Tawi Labs: coming soon

Labs adds features for teams and companies:
- connecting your own GPU servers, and deploying agents to them from the studio
- single sign-on
- organisations, teams and a larger shared drive
- an organisation audit trail
- a secure space with encryption at rest and backups

The studio marks these features as **Labs**.

Want to know when it's ready, or try it early? Write to hello@tawihub.com.
